# SweetCrumb Bakery — React Demo

Premium local-bakery website concept built with React + Vite.

## Run
1. Install Node.js 18+.
2. Open this folder in terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Included
- Glassmorphism / premium bakery UI
- Responsive desktop + mobile design
- Hero with animated background
- Category filters and live product search
- Product cards with add-to-basket interaction
- Cakes, bakery, bread, sweets/mithai, cookies and milk
- Delivery section
- Bakery story / values
- Testimonials and rating area
- Newsletter interaction
- WhatsApp demo order link
- Smooth scrolling and CSS animations

## Replace for the real bakery
- Bakery name/logo
- Phone / WhatsApp number
- Address
- Delivery areas
- Prices
- Product images
- Social links
- Order/checkout integration

## Image note
The demo references Unsplash-hosted images for the product photography. For a client production website, replace them with the bakery's own licensed/product photography or other appropriately licensed assets.
